# Learning Checklist

## Phase 0: Foundation

- [ ] I can explain why attribution is not causal.
- [ ] I can explain the role of incrementality testing.
- [ ] I can explain why Geo Lift is useful for media measurement.
- [ ] I can explain the purpose of MMM.
- [ ] I can explain why LTV matters for marketing decisions.
- [ ] I can explain the role of AI in a measurement copilot.

## Phase 1: Marketing Data Architecture

- [ ] I can define a marketing data model.
- [ ] I can create mock marketing datasets.
- [ ] I can write SQL staging models.
- [ ] I can design marketing mart tables.
- [ ] I can explain how dbt supports trusted analytics engineering.

## Phase 2: Attribution

- [ ] I can implement first-touch attribution.
- [ ] I can implement last-touch attribution.
- [ ] I can implement multi-touch attribution.
- [ ] I can explain Markov attribution.
- [ ] I can explain attribution limitations.

## Phase 3: Incrementality

- [ ] I can calculate experiment lift.
- [ ] I can estimate confidence intervals.
- [ ] I can calculate sample size and MDE.
- [ ] I can explain difference-in-differences.
- [ ] I can design a basic Geo Lift test.

## Phase 4: MMM

- [ ] I can explain adstock.
- [ ] I can explain saturation.
- [ ] I can build a simple regression-based MMM.
- [ ] I can interpret contribution, ROI, and marginal ROI.
- [ ] I can explain how experiments calibrate MMM.

## Phase 5: Lead Quality and LTV

- [ ] I can define lead quality.
- [ ] I can build a simple lead scoring model.
- [ ] I can estimate expected revenue.
- [ ] I can estimate expected LTV.
- [ ] I can compare channels by value, not just volume.

## Phase 6: Decision Engine

- [ ] I can define which method answers which business question.
- [ ] I can create channel-level decision rules.
- [ ] I can produce increase, hold, reduce, or test further recommendations.
- [ ] I can explain evidence strength and confidence.

## Phase 7: AI Measurement Copilot

- [ ] I can define AI use cases for measurement.
- [ ] I can create a prompt library.
- [ ] I can design AI guardrails.
- [ ] I can generate executive summaries from measurement outputs.
- [ ] I can design an AI experiment assistant.
